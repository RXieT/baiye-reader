# 1.3.0

## 阅读修正

- 阅读器回调读取当前配置，调整颜色和翻页动画后不再依赖重启；动画抓取前等待菜单退出绘制。
- 区分真实触控与程序滚动，拖动章节内页码滑块和工具栏切章不再触发菜单收起。
- 目录分卷增添展开/收起过渡；设置分类、选项和背景选择增加过渡。
- 字号仅保留在排版中；翻页动画名称统一为无动画、层叠、翻书。
- 继续阅读按钮同时显示已记录的章节。

## 书签与资源

- 阅读菜单的“更多 → 书签”可添加当前页、查看摘录、跳转及删除。
- 书签存储 CFI 与章节编号；线上目录顺序变化时优先恢复到对应章节。
- 阅读字体、界面字体、自定义背景支持删除确认；删除在用资源恢复默认，共用字体不会被误删。内置背景不能删除。

## 插图兼容

- 接纳上游公开示例使用的精确 CDN 与数字图片路径，不开放任意地址代理。
- 处理图片标记、XML/CDATA、HTML 正文；补充 WEBP/AVIF 签名判断及协议匹配的 Referer。
- 旧缓存首次访问尝试限时补抓，无网或失败仍保留原文，稍后可重试。
- 图片失败显示可点击重载状态；手动重载跳过旧图片缓存，不以整页错误中断阅读。

## 账号与评论

- 用户名/邮箱登录、用户资料及退出；登录成功需由用户信息接口确认。
- 评论主题与回复分页读取、发表主题、回复及失败草稿保留。
- 账号使用原项目的 HTTPS 中继；只保存 Keystore 加密会话，不保存密码。
- 发送绑定点击时的账号与书籍/主题上下文；不自动重发结果未确认的写入请求。

## 交付范围

本次按要求仅编译和打包，未运行测试、模拟器、实机或源站探测，未使用真实账号登录/发帖。插图实际 CDN、会话和评论现网兼容性仍需实际使用确认；不宣称已完成运行验证。
