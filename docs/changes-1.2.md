# 1.2

- 一级阅读菜单改为不压暗、不改变正文尺寸的悬浮小底栏。目录、排版、字体直接进入，背景和其他阅读设置收纳到更多。
- 滑块改为章节内页码，拖动立即定位，合并重复目标，不等待松手。手势翻页后收起底栏。
- 页码保留底部，只显示数字；章节名仍在上方。
- 取消正文点击后的人工等待。菜单进入先响应、短距离缓动停稳，退出更快；首页分类切换使用较短转场。
- 无动画、水平翻页、卷曲翻书三种选项。动画截图包括章节、时间与电量，卷曲使用网格变形、纸背和投影。
- 阅读目录与书籍详情均支持按卷折叠，当前章节所在卷展开。简介操作与正文独立。
- 加入简单背景纹理、图片导入和预设保存。导入字体可分别用于正文和应用界面，并可切回系统字体。
- 修正插图布局、受信任图片跳转与图片源协议兼容。只有列出的公开图片域名允许原有 HTTP 图片地址；文库接口与 WebView 仍使用 HTTPS。

未追加测试或模拟器验证，只编译安装包。
