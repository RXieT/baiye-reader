# 1.1

- 主导航改用 Miuix 原生 GlassNavigationBar，图标与背景采样模糊保留原组件交互。
- 文库接近列表底部时自动请求下一页，保留滚动位置。作者信息异步补齐，不阻塞首屏。
- 书籍按压、页面切换、列表移动与简介展开加入轻量动效。
- 新书阅读后进入书架；已移出书架的书不会因续读被重新收藏。长按管理区分移出、查看详情和删除。
- 阅读页保留章节、时间、电量和由内核计算的章节内页码。全书百分比与章节页码分开处理，不将估算位置当物理页数。
- 目录、排版、背景、阅读控制放在两级底部菜单，不重建正文。目录按卷分组并定位当前章节。
- 提供字重、段距、页边距、亮度、音量键、翻页动画及状态栏设置，夜间菜单避免白屏。
- 修正进度任务正常取消被误报为保存失败。进度写入合并，临时存储失败后台重试，不遮挡阅读。
- 封面、插图复用连接池，增加内存与磁盘缓存、相同图片请求合并、封面和下一章预取。
- 重复或仅影响原生控件的设置不触发正文 CSS 重排。时钟与电池状态单独更新。

阅读内核仍为固定版本 foliate-js，没有复制 Foliate 或 Readest 应用界面代码。按使用者要求，本轮仅编译交付，没有追加测试或模拟器验证。
